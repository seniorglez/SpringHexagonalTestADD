# Open questions

Written by the implementer when a spec is ambiguous, contradictory, or a frozen artefact seems wrong.
Answered by a human, who may then create a new baseline.

## Template

```
### Q-NN · <short title>
- Task: T0N
- Specs involved: <files and sections>
- Problem: <what is unclear or contradictory, with evidence such as a test output>
- Options considered: <A / B / ...>
- Recommendation: <option and why>
- Status: open
```
